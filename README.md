# Water Quality Index (WQI) Analysis

An advanced Excel-based environmental data analysis project evaluating water quality dynamics across various aquatic sampling locations. This project processes physio-chemical parameters—including pH, Dissolved Oxygen (DO), Electrical Conductivity (EC), Total Dissolved Solids (TDS), and Salinity—to compute the Water Quality Index (WQI) and classify suitability across Fresh, Marine, and Marine/Brine water types.

## 📊 Project Overview

This study analyzes water parameters from 17 key sampling locations (including Kolatoli, Sugandha, Laboni Beach, Inani Beach, Himchhari, and Shah-Porir Dweep) to monitor environmental health, assess pollutant concentrations, and categorize overall water quality classes.

## 📁 Repository Contents

* **`Water_Quality_Index_Analysis.xlsx`**: Main Excel workbook containing:
  * **Data Sheet**: Comprehensive dataset with measured parameters (pH, DO in mg/L, EC in µS/cm, TDS in ppm, Salinity in PSU, final WQI values, and water classifications).
  * **Pivot Table Sheet**: Statistical summaries evaluating parameter averages (pH, DO, TDS, WQI) categorized by water type and location breakdowns.
  * **Dashboard Sheet**: An interactive dashboard visualizing parameter variations, classification distributions, and dynamic filtering.
* **`Water_Quality_Index_Dashboard.png`**: High-resolution screenshot preview of the interactive Excel dashboard.

## 🛠️ Excel Techniques & Analytical Features Used

* **Physio-Chemical Parameter Calculation**: Automated calculation of WQI metrics based on pH, DO, EC, TDS, and Salinity.
* **Water Classification**: Grouping samples into quality tiers (*Unsuitable, Very Poor, Very Poor**).
* **Multi-Dimensional Pivot Analysis**: Grouped summaries by water type (*Fresh, Marine, Marine/Brine*) to evaluate spatial variations.
* **Interactive Dashboard Design**:
  * **Donut Chart**: Overall percentage visual breakdown of water quality classifications.
  * **Horizontal Bar Charts**: Location-wise WQI comparisons and parameter distribution across water types.
  * **Interactive Slicers**: Dynamic filtering by water *Class* and *Type*.

## 🚀 Getting Started

1. Download or clone this repository to your local machine.
2. Open **`Water_Quality_Index_Analysis.xlsx`** using Microsoft Excel.
3. Explore the worksheets to review the raw dataset, PivotTable aggregations, and test the interactive dashboard.
